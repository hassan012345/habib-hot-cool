# Habib Hot & Cool — Website

A responsive one-page Next.js website for Habib Hot & Cool, ready to deploy on Vercel.

## Included
- AC installation, repair, service and maintenance
- New and used AC buying/selling
- Solar panel washing
- Business profile highlighting 20+ years of experience and qualified professionals
- Tap-to-call and WhatsApp enquiry form
- Facebook and Instagram links
- Responsive mobile navigation and layout

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Import the repository at https://vercel.com/new.
3. Keep the framework preset as **Next.js** and click **Deploy**.

No environment variables are required. The contact form opens a pre-filled WhatsApp message to `03004120601` (international WhatsApp format `+92 300 4120601`).

## Before launch
- Confirm the service area/address and add it to the contact section if desired.
- Confirm that the photos load as expected; they are served from Unsplash URLs and need an internet connection.
- Review service wording and replace any photo with your own business/team photos for the most authentic result.
